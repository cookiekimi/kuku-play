# くくクエスト

家庭での個人学習用に制作した九九アプリです。キャラクターや既存作品のボールを使用せず、独自の宝石風ボールで成長を表現します。

## 遊び方

GitHub PagesのサイトをiPadのSafariで開きます。「共有」→「ホーム画面に追加」で使いやすくなります。初回はオンラインで開いてください。ファイルの保存が済むとオフラインでも練習できます。

- 1回10問。ランダム・各段・もういちどチャレンジ。
- 各段と全81問のランクはノーマル→スーパー→ハイパー→マスター。次までの残り数を表示。
- どの回答も3ポイント。ナイストライで星1個、その問題に再挑戦して正解すると星2個。
- 星を集めて6つの宝物を獲得。10回チャレンジしたことを祝う結果画面。
- 直近5回答の誤答率を色分けする、のびしろマップ。
- 最大5人のプロフィール。ニックネームを使ってください。

## 記録と公開範囲

サイトとソースは公開されています。アクセス制限はありません。名前・学習記録は端末内に保存し、アプリから外部へ送信しません。端末・ブラウザを変えても自動では同期しません。「おうちの人のせってい」から定期的にJSONバックアップを保存してください。バックアップはGitHubにアップロードしないでください。

検索結果に出にくくする指定をしていますが、秘密のサイトにはなりません。ブラウザのデータ削除で記録が消える場合があります。旧版のバックアップも読み込めます。

## 設置

GitHub Pagesをmainブランチの /docs から配信します。Cloudflareやカード登録は不要です。

## 確認

Node.jsで `node --test tests/core.test.cjs`。iPad Air 2実機での確認は利用端末で行ってください。
